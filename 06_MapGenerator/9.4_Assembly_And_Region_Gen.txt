## 2. 机械式步骤指令

### 2.1 Boss 城堡特定环带判定

**isBossCandidate(coordinate)**：

```
步骤 A：计算距离 d
步骤 B：候选条件 = (floor(d).toInt() % 10 == 0) && (d >= 9.5)
步骤 C：概率判定 = hash(seed + 10L, x, y) % 100 < 20（20% 出生率）
```

**getBossType(distance)**：

| 距离范围 | Boss 种类 |
|---------|----------|
| [9.5, 10.5]（d ≈ 10） | BOSS_KNIGHT（暗黑骑士） |
| [19.5, 20.5]（d ≈ 20） | BOSS_LAVA_GIANT（熔岩巨人） |
| d >= 29.5 且满足候选条件 | BOSS_FROST_WITCH（冰霜女巫） |

**完整实现**：

```kotlin
fun isBossCandidate(coordinate: Coordinate): Boolean {
    val d = getDistance(coordinate)
    if (d < 9.5) return false
    if (Math.floor(d).toInt() % 10 != 0) return false
    return (hash(seed + 10L, coordinate.x, coordinate.y) % 100).toInt() < 20
}

fun getBossType(distance: Double): String {
    return when {
        distance in 9.5..10.5 -> "BOSS_KNIGHT"
        distance in 19.5..20.5 -> "BOSS_LAVA_GIANT"
        distance >= 29.5 -> "BOSS_FROST_WITCH"
        else -> "BOSS_KNIGHT" // fallback
    }
}
```

### 2.2 稀疏城邦生成机制

**isCityStateCandidate(coordinate)**：

```
步骤 A：距离审查。若 d < 6.0，直接返回 false（新手安全岛）
步骤 B：动态密度核算
  - val roll = hash(seed + 4L, x, y) % 100
  - 若 6.0 <= d <= 15.0：密度 8%（roll < 8）
  - 若 d > 15.0：密度 5%（roll < 5）
```

**getCityStateType(coordinate)**：

```
val typeRoll = hash(seed + 5L, x, y) % 3
0 → "FARMING" | 1 → "MINING" | 其他 → "TRADING"
```

**完整实现**：

```kotlin
fun isCityStateCandidate(coordinate: Coordinate): Boolean {
    val d = getDistance(coordinate)
    if (d < 6.0) return false
    
    val roll = (hash(seed + 4L, coordinate.x, coordinate.y) % 100).toInt()
    val threshold = if (d <= 15.0) 8 else 5
    return roll < threshold
}

fun getCityStateType(coordinate: Coordinate): String {
    val typeRoll = (hash(seed + 5L, coordinate.x, coordinate.y) % 3).toInt()
    return when (typeRoll) {
        0 -> "FARMING"
        1 -> "MINING"
        else -> "TRADING"
    }
}
```

### 2.3 稀疏去重碰撞检测

**checkCityStateSparsity(coordinate, knownCityCoordinates)**：

```kotlin
fun checkCityStateSparsity(
    coordinate: Coordinate,
    knownCityCoordinates: Set<Coordinate>
): Boolean {
    for (known in knownCityCoordinates) {
        val dx = (coordinate.x - known.x).toDouble()
        val dy = (coordinate.y - known.y).toDouble()
        val dist = Math.sqrt(dx * dx + dy * dy)
        if (dist <= 5.0) return true  // 太挤，触发熔断
    }
    return false  // 无碰撞，放行
}
```

## 3. 禁止事项（硬性约束）

1. **大本营安全岛红线**：绝对禁止在欧氏拓扑距离 d < 6 的范围内生成任何城邦（城邦 d 必须 >= 6 才能浮现），且大本营 5×5 黄金区内也绝对不能产生 Boss，守护新手开局的安全期。

2. **禁止城邦紧密扎堆**：如果与 `knownCityCoordinates` 中任意已有城邦的欧氏距离 <= 5.0，必须彻底封杀此坐标的城邦生成权，强制维持荒野感。

3. **禁止使用 java.util.Random**：所有随机性必须通过 `hash(seed, x, y)` 计算。

4. **禁止 Boss 在安全区生成**：d < 9.5 的坐标永远不是 Boss 候选。

## 4. 测试规范：MapGenBossCityTest.kt

### 4.1 测试原则

⚠️ 确定性测试强制规则：Boss 候选判定和城邦类型必须幂等。

### 4.2 测试用例

**T01：特定环带 Boss 候选坐标判定测试**

- 目的：验证 Boss 仅在距离 10 整数倍环带生成
- 步骤：
  1. 模拟距离 d = 10.0 的坐标（如 Coordinate(6, 8)，距离恰好 10.0）
  2. 断言：如果哈希符合概率，`isBossCandidate` 判定为 `true`
  3. 断言：`getBossType(10.0)` 返回 `"BOSS_KNIGHT"`
  4. 模拟距离 d = 20.2 的坐标
  5. 断言：`getBossType(20.2)` 返回 `"BOSS_LAVA_GIANT"`
- 通过标准：环带判定和物种分类精确

**T02：城邦大本营安全隔离测试**

- 目的：验证 d < 6 的坐标不能生成城邦
- 步骤：
  1. 模拟距离 d = 4.0 的坐标（如 Coordinate(0, 4)）
  2. 断言：`isCityStateCandidate` 强制返回 `false`
- 通过标准：安全岛封杀城邦

**T03：城邦密度差异测试**

- 目的：验证近郊 (8%) 与远郊 (5%) 密度差异
- 步骤：
  1. 对大量坐标分别统计 d ∈ [6, 15] 和 d > 15 的城邦候选率
- 断言：近郊候选率约 8%，远郊候选率约 5%
- 通过标准：密度梯度正确

**T04：城邦物理邻近稀疏去重测试**

- 目的：验证碰撞检测精确拦截
- 步骤：
  1. 设定已知城邦集合 `setOf(Coordinate(8, 0))`
  2. 对临近坐标 `Coordinate(10, 1)`（距离 ≈ 2.24，小于 5.0）进行稀疏校验
  3. 断言：`checkCityStateSparsity` 返回 `true`，拦截生效
  4. 对远端坐标 `Coordinate(20, 20)` 进行校验
  5. 断言：返回 `false`，无碰撞，放行
- 通过标准：碰撞检测精确

**T05：城邦类型三分类测试**

- 目的：验证 FARMING/MINING/TRADING 三分类正确
- 步骤：
  1. 对多个坐标调用 `getCityStateType`
  2. 断言：结果只能是 "FARMING"、"MINING"、"TRADING" 之一
- 通过标准：分类正确无越界

**Boss 候选判定**：
```
isBossCandidate(Coordinate(6, 8))
  → d = 10.0
  → d >= 9.5 ✓
  → floor(10.0).toInt() % 10 == 0 ✓
  → hash(seed + 10L, 6, 8) % 100 < 20 ?
  → 假设命中 → true
  → 假设未命中 → false
```

**Boss 物种分类**：
```
getBossType(10.0)
  → 10.0 in 9.5..10.5 → "BOSS_KNIGHT"

getBossType(20.2)
  → 20.2 in 19.5..20.5 → "BOSS_LAVA_GIANT"

getBossType(30.0)
  → 30.0 >= 29.5 → "BOSS_FROST_WITCH"
```

**城邦候选判定**：
```
isCityStateCandidate(Coordinate(0, 4))
  → d = 4.0
  → d < 6.0 → false（安全岛封杀）

isCityStateCandidate(Coordinate(10, 0))
  → d = 10.0
  → 6.0 <= 10.0 <= 15.0 → 近郊密度 8%
  → roll = hash(seed + 4L, 10, 0) % 100
  → 假设 roll = 5 → 5 < 8 → true
```

**稀疏碰撞检测**：
```
checkCityStateSparsity(Coordinate(10, 1), setOf(Coordinate(8, 0)))
  → dx = 2, dy = 1
  → dist = sqrt(4 + 1) = 2.24
  → 2.24 <= 5.0 → true（熔断拦截）

checkCityStateSparsity(Coordinate(20, 20), setOf(Coordinate(8, 0)))
  → dx = 12, dy = 20
  → dist = sqrt(144 + 400) = 23.32
  → 23.32 > 5.0 → false（放行）
```
