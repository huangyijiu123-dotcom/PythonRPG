## 3. 基础 CRUD API

### 3.1 注册方法

**registerVillager(v: VillagerSnapshot)**：villagers[v.id] = v
**registerAdventurer(a: AdventurerSnapshot)**：adventurers[a.id] = a
**registerEquipment(eq: EquipmentSnapshot)**：equipments[eq.id] = eq
**registerCaravan(c: CaravanSnapshot)**：caravans[c.id] = c
**registerWarehouse(w: WarehouseSnapshot)**：warehouses[w.id] = w

**行为约束**：
- 直接存入对应 ConcurrentHashMap，覆盖已有键值
- 无返回值
- 线程安全由 ConcurrentHashMap 保证

### 3.2 获取方法

**getVillager(id: Long): VillagerSnapshot?**：villagers[id]
**getAdventurer(id: Long): AdventurerSnapshot?**：adventurers[id]
**getEquipment(id: Long): EquipmentSnapshot?**：equipments[id]
**getCaravan(id: Long): CaravanSnapshot?**：caravans[id]
**getWarehouse(id: Long): WarehouseSnapshot?**：warehouses[id]

**行为约束**：
- 返回快照对象引用（只读，外部不可修改内部状态）
- id 不存在时返回 null

### 3.3 全量获取方法

**getAllVillagers(): List<VillagerSnapshot>**：villagers.values.toList()
**getAllAdventurers(): List<AdventurerSnapshot>**：adventurers.values.toList()
**getAllEquipments(): List<EquipmentSnapshot>**：equipments.values.toList()
**getAllCaravans(): List<CaravanSnapshot>**：caravans.values.toList()
**getAllWarehouses(): List<WarehouseSnapshot>**：warehouses.values.toList()

**行为约束**：
- 返回不可变的 List 副本，禁止直接返回内部 Map 的 values 引用
- 使用 toList() 创建防御性拷贝

### 3.4 过滤方法

**filterVillagers(predicate: (VillagerSnapshot) -> Boolean): List<VillagerSnapshot>**：villagers.values.filter(predicate)
**filterAdventurers(predicate: (AdventurerSnapshot) -> Boolean)**：同上模式

**行为约束**：
- 返回过滤后的 List 副本
- predicate 在遍历期间执行，遍历完成后返回结果

### 3.5 删除方法

**removeVillager(id: Long): Boolean**：villagers.remove(id) != null
**removeAdventurer(id: Long): Boolean**：adventurers.remove(id) != null
**removeEquipment(id: Long): Boolean**：equipments.remove(id) != null
**removeCaravan(id: Long): Boolean**：caravans.remove(id) != null
**removeWarehouse(id: Long): Boolean**：warehouses.remove(id) != null

**行为约束**：
- 返回 Boolean 表示是否成功删除（id 存在返回 true，不存在返回 false）
- 删除后立即不可通过 get 查询到

## 4. 全局金币操作 API

### 4.1 getPlayerGold(): Int

**签名**：fun getPlayerGold(): Int

**返回值**：当前玩家金币数量

**原子性**：读取 AtomicInteger 的当前值，无锁

### 4.2 updatePlayerGold(delta: Int): Boolean

**签名**：fun updatePlayerGold(delta: Int): Boolean

**功能**：原子更新玩家金币数量

**实现**：
```kotlin
fun updatePlayerGold(delta: Int): Boolean {
    while (true) {
        val current = playerGold.get()
        val next = current + delta
        if (next < 0) return false
        if (playerGold.compareAndSet(current, next)) return true
    }
}
```

**行为约束**：
- 使用 CAS 循环确保原子性
- delta 为负数时扣除金币，若扣除后小于 0 则返回 false 且不修改
- delta 为正数时直接增加
- 并发调用时通过 CAS 重试保证最终一致性

**返回值**：
- true：更新成功
- false：扣除后金币不足，未执行修改

## 5. 禁止事项（硬性约束）

1. **禁止越界常识业务**：本模块是纯粹的内存型贫血数据库，严禁引入任何自动移动、寻路计算、AI 决策或时钟/协程循环
2. **禁止直接返回内部可变数据**：返回 List 或 Map 时必须使用 toList() 或 toMap() 创建防御性拷贝
3. **禁止非线程安全修改金币**：全局金币修改严禁直接 gold += delta，必须使用 CAS 循环
4. **禁止反射访问**：单元测试禁止通过反射读取内部 ConcurrentHashMap

## 6. 测试规范：EntityStateManagerBaseTest.kt

### 6.1 测试原则

⚠️ 黑盒测试强制规则：禁止使用反射或访问内部容器字段。所有验证必须通过公开 API 反映。

### 6.2 测试用例

**T01：基础 CRUD 注册获取测试**

- 目的：验证实体的注册、获取、全量获取和删除
- 步骤：
  1. 实例化 EntityStateManager
  2. 断言 getAllVillagers() 大小为 0
  3. 注册 VillagerSnapshot(id=1, name="张三", ...)
  4. 断言 getVillager(1)?.name == "张三"
  5. 断言 getAllVillagers() 大小为 1
  6. 调用 removeVillager(1)，断言返回 true
  7. 断言 getVillager(1) 返回 null
- 通过标准：所有断言通过

**T02：全局金币原子更新与边界测试**

- 目的：验证金币 CAS 更新的原子性和边界保护
- 步骤：
  1. 实例化 EntityStateManager，默认金币为 0
  2. updatePlayerGold(100) → 断言返回 true，getPlayerGold() == 100
  3. updatePlayerGold(-40) → 断言返回 true，getPlayerGold() == 60
  4. updatePlayerGold(-100) → 断言返回 false
  5. 断言 getPlayerGold() 仍为 60（扣除不足时安全回滚）
- 通过标准：边界保护正确，状态不回滚

**T03：全局金币高并发安全测试**

- 目的：验证 100 协程并发修改金币无状态丢失
- 步骤：
  1. 初始金币设为 1000
  2. 启动 50 个协程并行调用 updatePlayerGold(1)
  3. 启动 50 个协程并行调用 updatePlayerGold(-1)
  4. 等待所有协程结束
  5. 断言 getPlayerGold() 严格等于 1000
- 通过标准：无并发状态丢失

## 9. 快速行为查阅

**注册时序**：
```
registerVillager(v)
  → villagers[v.id] = v
  → 立即返回，覆盖已有值
```

**获取时序**：
```
getVillager(id)
  → villagers[id]
  → 返回快照引用或 null
```

**金币更新时序**：
```
updatePlayerGold(delta)
  → while(true) { current = get(); next = current + delta; if (next < 0) return false; if (CAS(current, next)) return true }
  → 失败时重试，负数时拒绝
```

**删除时序**：
```
removeVillager(id)
  → villagers.remove(id) != null
  → 返回 Boolean
```
