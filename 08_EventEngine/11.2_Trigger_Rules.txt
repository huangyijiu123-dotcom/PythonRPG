## 2. 机械式步骤指令与禁止事项

### 禁止事项：
1. **多重同灾爆发污染红线 (No Duplicate Event Spawns)**：
   对于具有全局持续性及 Boss 影响力的事件（如 `COLD_SNAP` 寒流突袭、`BOSS_RIOT` Boss骚乱），**绝对禁止在列表中同时生成两个及以上相同类型的事件**！在生成前必须先判定 `activeEvents.values.any { it.type == TARGET }`，若已存在则直接过滤拦截，避免灾难状态疯狂重叠导致数值崩坏。
2. **禁止空值引火**：森林火灾和洪水必须在获取到对应受灾建筑 ID 时才能诱发，无建筑时绝不无中生有。

### 机械式步骤指令：
1. **概率触发算法实现 (`tryTriggerEvents`)**：
   - **森林火灾 (FOREST_FIRE) 触发规约**：
     - 若 `conditionProvider.getCurrentWeather() == "DROUGHT"`：
       - 读取受灾建筑：`val targetB = conditionProvider.getRandomForestBuilding()`。
       - 若 $targetB$ 非空，且随机概率命中 $10\%$（即 `Random.nextInt(100) < 10`）：
         - 创造火灾事件：`ActiveEvent(eventIdGenerator.getAndIncrement(), EventType.FOREST_FIRE, null, null, targetB, remainingTicks = 4, severity = 2)`。
         - 调用 `registerEvent` 注册事件并向 SharedFlow 广播 `"SPAWNED"`。
   - **洪水泛滥 (FLOOD) 触发规约**：
     - 若 `conditionProvider.getCurrentWeather() == "RAIN"`：
       - 获取受阻农田：`val targetF = conditionProvider.getRandomFarmBuilding()`。
       - 若 $targetF$ 非空，且随机概率命中 $10\%$（即 `Random.nextInt(100) < 10`）：
         - 创造洪水：`ActiveEvent(eventIdGenerator.getAndIncrement(), EventType.FLOOD, null, null, targetF, remainingTicks = 4, severity = 2)`。
         - 注册并广播。
   - **寒流突袭 (COLD_SNAP) 触发规约**：
     - 若 `conditionProvider.getCurrentWeather() == "COLD_WAVE"`：
       - **重复去重校验**：若 `activeEvents.values.none { it.type == EventType.COLD_SNAP }`：
         - 若随机概率命中 $20\%$（即 `Random.nextInt(100) < 20`）：
           - 创造寒流：`ActiveEvent(eventIdGenerator.getAndIncrement(), EventType.COLD_SNAP, null, null, null, remainingTicks = 6, severity = 3)`。
           - 注册并广播。
   - **Boss 暴动 (BOSS_RIOT) 触发规约**：
     - 若 `conditionProvider.hasUndefeatedBoss() == true`：
       - **重复去重校验**：若 `activeEvents.values.none { it.type == EventType.BOSS_RIOT }`：
         - 若随机概率命中 $5\%$（即 `Random.nextInt(100) < 5`）：
           - 创造 Boss 骚乱：`ActiveEvent(eventIdGenerator.getAndIncrement(), EventType.BOSS_RIOT, null, null, null, remainingTicks = -1, severity = 5)`（-1 表示无限持续直到被清理）。
           - 注册并广播。

## MDU 11.2-TEST: 环境灾难触发概率与去重碰撞黑盒测试
