# MDU 15.1: 锻造配方与强化规则配置 (MDU-A: Data Models & Configurations)

作为 AI 装备锻造强化专家，你的任务是为铁匠铺系统定义锻造排队数据结构、只读硬编码的装备制造静态配方以及装备精炼强化阶段的成功概率与资源消耗规则矩阵。

---

## 1. 锻造强化数据与配方契约 (Data Contract)

在桥接器中定义以下核心任务实体、静态配方配置类以及强化规则结构（确保数据参数完全精确锁定）：

```kotlin
// 1. 实时锻造任务快照
data class ForgeTask(
    val taskId: Long,
    val equipmentTemplateId: String,       // 目标装备模板 ID（如 "IRON_SWORD"）
    var currentProgress: Int,              // 当前制造进度 Tick
    val requiredTicks: Int                 // 制造此装备所需总 Tick
)

// 2. 装备制造基础配方配置类
data class EquipmentRecipe(
    val equipmentClass: String,            // 装备大类："WEAPON" 武器 或 "ARMOR" 防具
    val woodCost: Int,                     // 制造木材消耗
    val stoneCost: Int,                    // 制造石材消耗
    val ironCost: Int,                     // 制造铁矿消耗
    val goldCost: Int,                     // 制造金币消耗
    val obsidianCost: Int,                 // 制造黑曜石消耗
    val maxDurability: Int,                // 出厂最大耐久度
    val baseStat: Int,                     // 基础属性（武器对应攻击，防具对应防御）
    val requiredTicks: Int                 // 基础制造耗时 Tick
)

// 3. 单级精炼强化规则类
data class RefineRule(
    val successChance: Double,             // 强化成功率（0.0 ~ 1.0）
    val downgradePenalty: Int,             // 失败降级惩罚（降几级）
    val woodCost: Int,                     // 强化所需木材消耗
    val stoneCost: Int,                    // 强化所需石材消耗
    val ironCost: Int,                     // 强化所需铁矿消耗
    val goldCost: Int,                     // 强化所需金币消耗
    val obsidianCost: Int                  // 强化所需黑曜石消耗
)

// 4. 外部装备实体镜像，用以交互校验 (见 03_EntityStateManager)
data class EquipmentSnapshot(
    val equipmentId: Long,
    val templateId: String,
    val equipmentClass: String,
    var level: Int,
    var baseStat: Int,
    var currentStat: Int,
    var durability: Int,
    val maxDurability: Int,
    var ownerId: Long?
)
```

## 2. 机械式步骤指令与禁止事项

### 禁止事项：
1. **装备造价及强化成功率篡改红线 (Strict Forge Rules)**：
   铁剑铁甲的**基础配方和 +1 ~ +10 的成功概率矩阵必须静态硬编码锁定**，绝对禁止在运行时动态调整强化偏好概率，确保游戏经营数值杠杆的物理平衡。
2. **禁止参数空缺**。

### 机械式步骤指令：
1. **硬编码静态装备制造配方字典配置**（在 `ForgeEngine` 内部声明 `val templates: Map<String, EquipmentRecipe>`）：
   - `"IRON_SWORD"` (铁剑)：WEAPON 大类，木材 10，石材 5，铁矿 15，金币 30，黑曜石 0，最大耐久 200，基础攻击 20，5 Ticks。
   - `"IRON_ARMOR"` (铁甲)：ARMOR 大类，木材 5，石材 10，铁矿 20，金币 40，黑曜石 0，最大耐久 200，基础防御 15，6 Ticks。
2. **硬编码静态强化成功率与消耗配置映射表**：
   - 实现查表接口 `fun getRefineRule(currentLevel: Int): RefineRule`。入参为当前强化等级（如当前为 3 级，代表尝试升至 4 级）：
     - `0` 级、`1` 级、`2` 级（升至 +1..+3）：成功率 `1.0` (100%)，降级 `0`，木材 10，石材 5，其他 0。
     - `3` 级、`4` 级、`5` 级（升至 +4..+6）：成功率 `0.7` (70%)，降级 `1`，铁矿 8，金币 20，其他 0。
     - `6` 级、`7` 级、`8` 级（升至 +7..+9）：成功率 `0.4` (40%)，降级 `1`，铁矿 15，金币 50，其他 0。
     - `9` 级（升至 +10）：成功率 `0.25` (25%)，降级 `2`，黑曜石 5，金币 200，其他 0。
     - 大于等于 `10` 级：直接返回零成功率，防止越级。
3. **构建高安全的并发状态字典**：
   - 实例化 `class ForgeEngine`。
   - 内部维护并发安全的锻造任务队列和全局自增 ID 发生器：
     - `private val activeTasks = CopyOnWriteArrayList<ForgeTask>()`
     - `private val equipmentIdGenerator = AtomicLong(1001L)`
     - `private val taskIdGenerator = AtomicLong(1L)`
