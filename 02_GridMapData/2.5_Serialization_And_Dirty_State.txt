## 2. 机械式步骤指令

### 2.1 声明脏队列与更新流

**声明并发安全的脏坐标缓存队列**：

```kotlin
private val dirtyQueue = ConcurrentLinkedQueue<Coordinate>()
```

**声明私有流（带 DROP_OLDEST 背压）**：

```kotlin
private val _dirtyTilesFlow = MutableSharedFlow<List<Coordinate>>(
    replay = 0,
    extraBufferCapacity = 10,
    onBufferOverflow = BufferOverflow.DROP_OLDEST
)

// 暴露只读属性
val dirtyTilesFlow = _dirtyTilesFlow.asSharedFlow()
```

### 2.2 脏标记插桩

⚠️ **重要**：只有当格子写入成功或属性确实发生变更时才加入队列。

**修改 `setTile(tile)`**：
```kotlin
fun setTile(tile: TileData) {
    val key = packToLong(tile.coordinate.x, tile.coordinate.y)
    tileMap[key] = tile
    dirtyQueue.add(tile.coordinate)  // 插入成功后标记
}
```

**修改 `batchUpdateTiles(tiles)`**：
```kotlin
suspend fun batchUpdateTiles(tiles: List<TileData>) {
    batchMutex.withLock {
        for (tile in tiles) {
            val key = packToLong(tile.coordinate.x, tile.coordinate.y)
            tileMap[key] = tile
            dirtyQueue.add(tile.coordinate)  // 每个格子标记
        }
    }
}
```

**修改原子更新方法（updateExploreStatus / updateMonsterPresence / updateBuilding）**：

以 `updateExploreStatus` 为例：
```kotlin
fun updateExploreStatus(coordinate: Coordinate, status: ExploreStatus): Boolean {
    val key = packToLong(coordinate.x, coordinate.y)
    val result = tileMap.computeIfPresent(key) { _, oldTile ->
        oldTile.copy(exploreStatus = status)
    }
    if (result != null) {
        dirtyQueue.add(coordinate)  // 更新成功后才标记
    }
    return result != null
}
```

**修改 `unlockTile(coordinate)`**：

将目标格子和所有新变可见的邻居格子全部标记：
```kotlin
fun unlockTile(coordinate: Coordinate): List<Coordinate> {
    val targetKey = packToLong(coordinate.x, coordinate.y)
    
    val currentTile = tileMap[targetKey] ?: return emptyList()
    if (currentTile.exploreStatus != ExploreStatus.VISIBLE_UNEXPLORED) {
        return emptyList()
    }
    
    tileMap.computeIfPresent(targetKey) { _, old ->
        old.copy(exploreStatus = ExploreStatus.EXPLORED)
    }
    
    val newlyVisible = mutableListOf<Coordinate>()
    val directions = listOf(Pair(0, 1), Pair(0, -1), Pair(1, 0), Pair(-1, 0))
    
    for ((dx, dy) in directions) {
        val neighborCoord = Coordinate(coordinate.x + dx, coordinate.y + dy)
        val neighborKey = packToLong(neighborCoord.x, neighborCoord.y)
        
        val neighborTile = tileMap[neighborKey] ?: continue
        
        if (neighborTile.exploreStatus == ExploreStatus.UNEXPLORED) {
            tileMap.computeIfPresent(neighborKey) { _, old ->
                old.copy(exploreStatus = ExploreStatus.VISIBLE_UNEXPLORED)
            }
            newlyVisible.add(neighborCoord)
        }
    }
    
    // 目标格子 + 所有新变可见邻居全部标记为脏
    dirtyQueue.add(coordinate)
    for (nc in newlyVisible) {
        dirtyQueue.add(nc)
    }
    
    return newlyVisible
}
```

### 2.3 实现打包发射逻辑

```kotlin
fun emitDirtyTiles() {
    val list = ArrayList<Coordinate>()
    while (true) {
        val coord = dirtyQueue.poll() ?: break
        list.add(coord)
    }
    if (list.isNotEmpty()) {
        _dirtyTilesFlow.tryEmit(list)
    }
}
```

### 2.4 实现 Gson 存档往返

**exportToJson()**：

```kotlin
fun exportToJson(): String {
    return Gson().toJson(tileMap.values.toList())
}
```

**importFromJson(json)**：

```kotlin
fun importFromJson(json: String) {
    // 步骤 A：双重清空
    tileMap.clear()
    dirtyQueue.clear()
    
    // 步骤 B：解析 JSON
    val tiles = Gson().fromJson(json, Array<TileData>::class.java)
    
    // 步骤 C：重新注入
    for (tile in tiles) {
        val key = packToLong(tile.coordinate.x, tile.coordinate.y)
        tileMap[key] = tile
    }
}
```

## 3. Gson 数值类型陷阱（硬性约束）

### 3.1 禁止使用 kotlinx.serialization

**强制原因**：`TileData` 中预留的 `customAttributes: Map<String, Any>` 在非预定义多态环境下会导致反序列化强转崩溃。Gson 具有天然动态解析 Map 的能力。

### 3.2 Gson 数值类型反序列化陷阱

Gson 在反序列化 `Map<String, Any>` 时，**会将所有 JSON number 类型还原为 `Double`**（即使原始存入的是 `Int`）。

**陷阱示例**：
```kotlin
// 存入时
customAttributes["gold"] = 500  // Int

// 读取时 - 错误做法
val gold = customAttributes["gold"] as Int  // ClassCastException！

// 读取时 - 正确做法
val gold = (customAttributes["gold"] as Number).toInt()  // 500
```

**命名约定**：对 `customAttributes` 中数字类型的读取，全项目统一使用 `(value as Number).toInt()` / `.toLong()` / `.toDouble()` 进行安全转换。

---

## 4. 禁止事项（硬性约束）

1. **禁止使用 kotlinx.serialization**：必须使用 Gson 进行序列化/反序列化。

2. **禁止在发射时挂起**：必须使用 `tryEmit` 非阻塞发射，严禁使用会挂起的 `emit`。

3. **禁止脏标记遗漏**：所有写操作成功后必须标记脏坐标，包括 `setTile`、`batchUpdateTiles`、`updateXXX`（成功时）、`unlockTile`（目标+邻居）。

4. **禁止直接强转 Number 类型**：`customAttributes` 中的数值必须使用 `(value as Number).toXxx()` 安全转换。

5. **禁止遗漏双重清空**：`importFromJson` 必须先清空 `tileMap` 再清空 `dirtyQueue`，防止脏数据残留。

## 9. 语义级冻结声明

当本 MDU 及其配套测试完全通过后，`GridMapData` 核心语义冻结。

### 9.1 冻结语义边界

1. **沙箱边界**：本模块是一个纯粹的空间格子内存型容器，完全封死任何寻路算法、UI 绘制、村民移动等逻辑；仅通过 `dirtyTilesFlow` 提供增量脏通知。

2. **底层索引冻结**：底层使用 `packToLong` 的位位移压缩 Long 作为 Key。

3. **读写隔离与更新并发原语**：单点更新锁定为 `computeIfPresent` 槽锁；大面积读写使用 `Mutex` 锁进行临界区包裹。

4. **存档引擎锁定**：存档格式锁定为通过 Gson 执行的 JSON 往返，确保 `Map<String, Any>` 自定义属性的极简多态支持。

5. **初始地图状态注入归属合约**：本模块不持有任何默认初始状态。游戏启动时的初始地图数据（包括大本营 (0,0) 已探索状态与周围 5×5 固定模板，说明书 §4.4.6）由模块 `09_MapGenerator` 在游戏初始化时通过 `batchUpdateTiles` 方法统一注入。`GridMapData` 不主动感知「游戏开始」事件，也不包含任何糖化构造逻辑。

### 9.2 允许进化范围 (Permitted Evolutions)

- 允许通过 Patch 扩展 `TileData` 的非关键字段
- 允许在 `customAttributes` 注入更多维度的复杂属性
- 禁止回改以上五条冻结的核心并发与读写隔离语义

## 10. 快速行为查阅

**脏标记时序**：
```
setTile(tile)
  → tileMap[key] = tile
  → dirtyQueue.add(tile.coordinate)
  → 返回 Unit
```

**批量写入脏标记**：
```
batchUpdateTiles(tiles)
  → batchMutex.withLock {
      for (tile in tiles) {
        tileMap[key] = tile
        dirtyQueue.add(tile.coordinate)  // 每个格子均标记
      }
    }
```

**原子更新脏标记**：
```
updateExploreStatus(coord, EXPLORED)
  → computeIfPresent 返回非空（更新成功）
  → dirtyQueue.add(coord)
  → 返回 true
  → （更新失败时返回 null，不标记脏）
```

**解锁脏标记（目标 + 邻居）**：
```
unlockTile(Coordinate(5, 5))
  → 目标格子(5,5) computeIfPresent 更新为 EXPLORED
  → 邻居(5,6)/(5,4)/(6,5)/(4,5) 逐一检查并更新为 VISIBLE_UNEXPLORED
  → dirtyQueue.add(Coordinate(5, 5))  // 目标
  → dirtyQueue.add(neighbor)          // 每个新变可见邻居
  → 返回新变可见邻居列表
```

**发射时序**：
```
emitDirtyTiles()
  → list = ArrayList()
  → while (coord = dirtyQueue.poll()) list.add(coord)
  → dirtyQueue.poll() returns null 时退出
  → if (list.notEmpty) _dirtyTilesFlow.tryEmit(list)
  → 返回 Unit
```

**Gson 存档导出**：
```
exportToJson()
  → Gson().toJson(tileMap.values.toList())
  → 返回 JSON 字符串
```

**Gson 存档导入**：
```
importFromJson(json)
  → tileMap.clear()
  → dirtyQueue.clear()
  → tiles = Gson().fromJson(json, Array<TileData>::class.java)
  → for (tile in tiles) tileMap[key] = tile
  → 返回 Unit
```

**Gson 数值安全读取**：
```
customAttributes["gold"]  // 原始值：Int 500
  → Gson 反序列化后：Double 500.0
  → (customAttributes["gold"] as Number).toInt() == 500  // 安全转换
  → customAttributes["gold"] as Int  // ClassCastException!
```
