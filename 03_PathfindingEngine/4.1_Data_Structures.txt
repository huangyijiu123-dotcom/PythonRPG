### 2.2 实现测距方法

**manhattanDistance**（曼哈顿距离）：

```kotlin
fun manhattanDistance(from: Coordinate, to: Coordinate): Int {
    return kotlin.math.abs(from.x - to.x) + kotlin.math.abs(from.y - to.y)
}
```

公式：|from.x - to.x| + |from.y - to.y|

**euclideanDistance**（欧几里得距离）：

```kotlin
fun euclideanDistance(from: Coordinate, to: Coordinate): Double {
    val dx = (from.x - to.x).toDouble()
    val dy = (from.y - to.y).toDouble()
    return kotlin.math.sqrt(dx * dx + dy * dy)
}
```

公式：√((from.x - to.x)² + (from.y - to.y)²)

### 2.3 定义高性能私有辅助节点 Node

```kotlin
private class Node(
    val x: Int,
    val y: Int,
    val g: Int,       // 起点到当前节点的实际代价
    val h: Int,       // 当前节点到终点的预估启发式代价
    val parent: Node?  // 逆向回溯 parent 指针
) {
    val f: Int get() = g + h
}
```

### 2.4 定义 PriorityQueue 排序 Comparator

```kotlin
private val nodeComparator = Comparator<Node> { n1, n2 ->
    n1.f.compareTo(n2.f)
}
```

排序规则：f 值越小的节点优先级越高（排在前面）。

## 4. 测试规范：PathfindingEngineMathTest.kt

### 4.1 测试原则

⚠️ 纯数学测试：仅验证测距函数和 Node 排序，不涉及寻路主逻辑。

### 4.2 测试用例

**T01：曼哈顿距离边界值测试**

- 目的：验证曼哈顿距离在零距离、正数象限、负数跨象限场景下的精确性
- 步骤：
  1. 测试 Coordinate(5, 5) 到 Coordinate(5, 5)
  2. 断言：距离 == 0（同一点）
  3. 测试 Coordinate(0, 0) 到 Coordinate(3, 4)
  4. 断言：距离 == 7（|0-3| + |0-4| = 3 + 4）
  5. 测试 Coordinate(-2, -3) 到 Coordinate(2, 3)
  6. 断言：距离 == 10（|-2-2| + |-3-3| = 4 + 6）
- 通过标准：三场景精确

**T02：欧几里得距离勾股定理校验**

- 目的：验证欧氏距离勾股定理精确性
- 步骤：
  1. 测试 Coordinate(0, 0) 到 Coordinate(3, 4)
  2. 断言：距离 == 5.0（精确 Double 值，勾股定理 3²+4²=25 → √25=5）
  3. 测试 Coordinate(-1, -1) 到 Coordinate(2, 3)
  4. 断言：距离 == 5.0（√(3²+4²) = 5.0）
- 通过标准：勾股定理精确

**T03：Node 排序优先级验证**

- 目的：验证 f 值越小优先级越高
- 步骤：
  1. 构造 Node A（g=10, h=5 → f=15）
  2. 构造 Node B（g=5, h=8 → f=13）
  3. 使用 nodeComparator 比较
- 断言：Node B 排在 Node A 之前（13 < 15）
- 通过标准：f 值排序正确

**T04：同 f 值排序稳定性测试**

- 目的：验证 f 值相同时不崩溃
- 步骤：
  1. 构造 Node A（g=5, h=5 → f=10）
  2. 构造 Node B（g=3, h=7 → f=10）
  3. 使用 nodeComparator 比较
- 断言：比较结果 == 0（同优先级）
- 通过标准：不崩溃

## 8. 快速行为查阅

**曼哈顿距离**：
```
manhattanDistance(Coordinate(0, 0), Coordinate(3, 4))
  → |0 - 3| + |0 - 4|
  → 3 + 4 = 7

manhattanDistance(Coordinate(-2, -3), Coordinate(2, 3))
  → |-2 - 2| + |-3 - 3|
  → 4 + 6 = 10
```

**欧几里得距离**：
```
euclideanDistance(Coordinate(0, 0), Coordinate(3, 4))
  → √((0-3)² + (0-4)²)
  → √(9 + 16)
  → √25 = 5.0
```

**Node f 值排序**：
```
Node(g=10, h=5) → f = 15
Node(g=5,  h=8) → f = 13

nodeComparator(A, B) → 13 vs 15 → B 排在前面（f 越小越优先）
```
