# MDU 3.4: 增量脏数据流、全量存档序列化与语义冻结

## 任务目标

为 `EntityStateManager` 建立轻量级 UI 状态同步增量通知通道、基于 Gson 2.x 的全量数据持久化存档以及进行模块的语义级冻结声明。

**输出标准**：脏数据流使用 `DROP_OLDEST` 背压策略，序列化强制使用 Gson，禁止 `kotlinx.serialization`。所有发射操作必须非阻塞。

## 1. 核心数据与接口契约

### 1.1 StateDiff 数据类

```kotlin
// 脏数据变化集（记录自上次发射以来有哪些实体的 ID 发生了变更）
data class StateDiff(

    val adventurers: List<Long>,
    val caravans: List<Long>,
    val warehouses: List<Long>,
    val equipments: List<Long>,
```

### 1.2 增量脏数据只读广播流

```kotlin
// 暴露只读属性
val stateDiffFlow: SharedFlow<StateDiff>

// 私有流声明
private val _stateDiffFlow = MutableSharedFlow<StateDiff>(

    extraBufferCapacity = 10,

```

## 2. 机械式步骤指令

### 2.1 声明脏数据缓存集

在 `EntityStateManager` 内部定义并发安全的脏数据 ID 缓存集：

```kotlin
private val dirtyVillagers = ConcurrentHashMap.newKeySet<Long>()
private val dirtyAdventurers = ConcurrentHashMap.newKeySet<Long>()
private val dirtyCaravans = ConcurrentHashMap.newKeySet<Long>()
private val dirtyWarehouses = ConcurrentHashMap.newKeySet<Long>()
private val dirtyEquipments = ConcurrentHashMap.newKeySet<Long>()
private val goldChanged = AtomicBoolean(false)
```

### 2.2 底层写操作增量插桩 (Dirty Hooking)

在所有增加、移除、修改单体属性方法中，一旦操作判定成功，将实体 ID 添加到对应脏集合：

**单体更新成功后**：
- `updateVillagerEnergy(id, ...)` 成功 → `dirtyVillagers.add(id)`
- `updateAdventurerHp(id, ...)` 成功 → `dirtyAdventurers.add(id)`
- `updateEquipmentDurability(id, ...)` 成功 → `dirtyEquipments.add(id)`
- `updateCaravanCargo(id, ...)` 成功 → `dirtyCaravans.add(id)`
- `updateWarehouseInventory(id, ...)` 成功 → `dirtyWarehouses.add(id)`

**注册/删除成功后**：
- `registerVillager(v)` → `dirtyVillagers.add(v.id)`
- `removeVillager(id)` 返回 true → `dirtyVillagers.add(id)`

**全局金币更新成功后**：
- `updatePlayerGold(delta)` CAS 成功 → `goldChanged.set(true)`

**跨实体转移成功后**：
- `transferItemVillagerToWarehouse(...)` 成功 → `dirtyVillagers.add(villagerId)` + `dirtyWarehouses.add(warehouseId)`
- `transferItemCaravanToWarehouse(...)` 成功 → `dirtyCaravans.add(caravanId)` + `dirtyWarehouses.add(warehouseId)`
- `transferItemWarehouseToCaravan(...)` 成功 → `dirtyWarehouses.add(warehouseId)` + `dirtyCaravans.add(caravanId)`

### 2.3 实现广播发射 (emitStateDiff)

```kotlin
fun emitStateDiff() {
    val vList = dirtyVillagers.toList(); dirtyVillagers.clear()
    val aList = dirtyAdventurers.toList(); dirtyAdventurers.clear()
    val cList = dirtyCaravans.toList(); dirtyCaravans.clear()
    val wList = dirtyWarehouses.toList(); dirtyWarehouses.clear()
    val eList = dirtyEquipments.toList(); dirtyEquipments.clear()
    val goldWasChanged = goldChanged.getAndSet(false)

    if (vList.isNotEmpty() || aList.isNotEmpty() || cList.isNotEmpty() || 
        wList.isNotEmpty() || eList.isNotEmpty() || goldWasChanged) {
        _stateDiffFlow.tryEmit(StateDiff(vList, aList, cList, wList, eList, goldWasChanged))
    }
}
```

### 2.4 Gson 存档引擎往返实现

**定义 SaveData 承载类**：

```kotlin
data class SaveData(
    val villagers: List<VillagerSnapshot>,
    val adventurers: List<AdventurerSnapshot>,
    val caravans: List<CaravanSnapshot>,
    val warehouses: List<WarehouseSnapshot>,
    val equipments: List<EquipmentSnapshot>,
    val playerGold: Int
)
```

**exportStateToJson()**：
```kotlin
fun exportStateToJson(): String {
    val saveData = SaveData(
        villagers = villagers.values.toList(),
        adventurers = adventurers.values.toList(),
        caravans = caravans.values.toList(),
        warehouses = warehouses.values.toList(),
        equipments = equipments.values.toList(),
        playerGold = getPlayerGold()
    )
    return Gson().toJson(saveData)
}
```

**loadStateFromJson(json)**：
```kotlin
fun loadStateFromJson(json: String) {
    // 步骤 A：清空现有 Map
    villagers.clear()
    adventurers.clear()
    equipments.clear()
    caravans.clear()
    warehouses.clear()

    // 步骤 B：重置脏数据追踪
    dirtyVillagers.clear()
    dirtyAdventurers.clear()
    dirtyCaravans.clear()
    dirtyWarehouses.clear()
    dirtyEquipments.clear()
    goldChanged.set(false)

    // 步骤 C：解析 JSON
    val data = Gson().fromJson(json, SaveData::class.java)

    // 步骤 D：重新注入
    villagers.putAll(data.villagers.associateBy { it.id })
    adventurers.putAll(data.adventurers.associateBy { it.id })
    caravans.putAll(data.caravans.associateBy { it.id })
    warehouses.putAll(data.warehouses.associateBy { it.id })
    equipments.putAll(data.equipments.associateBy { it.id })
    playerGold.set(data.playerGold)
}
```

## 3. 禁止事项（硬性约束）

1. **禁止使用 kotlinx.serialization**：出于全平台（Chaquopy Python 端）数据多态互操作性以及防范类型擦除崩溃，强制使用 Gson。

2. **禁止在脏流发射时挂起/阻塞**：`stateDiffFlow` 底层必须配置 `DROP_OLDEST` 背压策略，严禁使用会引发协程永久挂起的 `emit` 方法，必须且仅能使用非阻塞的 `tryEmit`。

3. **禁止遗漏脏标记**：任何成功的写操作（单体更新、注册、删除、跨实体转移、金币更新）必须立即标记对应实体为脏，否则 UI 将错过状态变更通知。

4. **禁止存档包含脏状态**：`exportStateToJson()` 只导出实体数据和金币，不导出脏标记集合。

### 4.2 测试用例

**T01：增量脏通知发射与背压防阻塞验证**

- 目的：验证脏数据流正确发射且不会阻塞
- 步骤：
  1. 实例化 `EntityStateManager`，监听 `stateDiffFlow`
  2. 注册村民 1，更新其体力
  3. 断言：此时 `stateDiffFlow` 未发出任何数据（尚未调用 emit）
  4. 调用 `emitStateDiff()`
  5. 断言 1：订阅者收到且仅收到 1 次 `StateDiff`，`villagers` 包含 `1`
  6. 连续触发 50 次 `emitStateDiff()`
  7. 断言 2：调用立即返回，无任何挂起与阻塞
- 通过标准：发射正确，无阻塞

**T02：Gson 复杂存档回环精度验证**

- 目的：验证 Gson 序列化/反序列化完整保留数据
- 步骤：
  1. 注册村民 1（energy = 85, backpack = `{"WOOD" to 10}`）
  2. 增加玩家金币 500
  3. 调用 `exportStateToJson()` 导出 JSON
  4. 调用 `loadStateFromJson(json)`
  5. 断言 1：全局金币还原为 500
  6. 断言 2：村民 1 数据完整恢复，背包 `"WOOD"` 为 10，体力为 85
  7. 验证数值可安全读取，无强转崩溃
- 通过标准：数据完整回环，无精度丢失

## 8. 语义级冻结声明

当本 MDU 及其配套测试完全通过后，`EntityStateManager` 核心语义冻结。

### 8.1 冻结语义边界

1. **沙箱与单向读写隔离**：本模块是纯粹的贫血领域空间内存仓库，完全封死任何自动寻路、UI 绘制、村民移动等 AI 决策；仅通过 `stateDiffFlow` 提供增量脏通知，写操作完全依赖外部 ActionProcessor 主动发起。

2. **全局更新排他原语**：单体更新锁定为 `computeIfPresent` 槽锁；跨实体事务写锁定为全局 `Mutex`。

3. **存档引擎锁定**：存档格式锁定为通过 Gson 执行的 JSON 往返，防范 kotlinx 类型擦除。

### 8.2 允许进化范围 (Permitted Evolutions)

- 允许通过 Patch 扩展 Snapshot 类的数据字段（如添加专长列表、装备栏等）
- 禁止修改以上三条冻结的核心并发与事务读写隔离语义

## 9. 快速行为查阅

**脏标记时序**：
```
updateVillagerEnergy(1, 90)
  → computeIfPresent { old -> old.copy(energy = 90) }
  → dirtyVillagers.add(1)
  → 返回 true
```

**发射时序**：
```
emitStateDiff()
  → vList = dirtyVillagers.toList(); dirtyVillagers.clear()
  → aList = dirtyAdventurers.toList(); dirtyAdventurers.clear()
  → ...
  → if (any list not empty) _stateDiffFlow.tryEmit(StateDiff(vList, ...))
  → 返回 Unit
```

**存档导出时序**：
```
exportStateToJson()
  → saveData = SaveData(villagers.values.toList(), adventurers.values.toList(), ...)
  → Gson().toJson(saveData)
  → 返回 JSON 字符串
```

**存档导入时序**：
```
loadStateFromJson(json)
  → villagers.clear(); adventurers.clear(); ...
  → dirtyVillagers.clear(); dirtyAdventurers.clear(); ...
  → data = Gson().fromJson(json, SaveData::class.java)
  → villagers.putAll(data.villagers.associateBy { it.id })
  → playerGold.set(data.playerGold)
  → 返回 Unit
```
